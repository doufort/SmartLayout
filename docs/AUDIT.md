# Аудит SmartLayout 1.0

Что проверялось: релиз `dist/SmartLayout-1.0.dmg` (бинарник, Info.plist, LaunchAgent, ресурсы) и исходники из `SmartLayout_v_1.zip`. Для сравнения взят [RuSwitcher](https://github.com/rashn/RuSwitcher), открытый переключатель раскладки для macOS.

Как воспроизвести:

```bash
python3 -m pytest              # словари, исходники, релизный .dmg (работает и на Linux)
swift test                     # логика на Swift (нужен Mac)
python3 tools/bundle.py        # отчёт по сборке: архитектуры, подпись, версия
```

Тесты с пометкой xfail и ссылкой `AUDIT #N` описывают проблемы релиза 1.0. На сборке из текущих исходников эти же тесты должны проходить.

## Что осталось за вами

- **Подпись Developer ID и нотаризация.** Нужен платный аккаунт Apple Developer. Когда он будет: `SIGN_ID="Developer ID Application: Имя (TEAMID)" NOTARY_PROFILE=smartlayout ./build_app.sh dmg`. Профиль создаётся один раз: `xcrun notarytool store-credentials smartlayout`.
- **Если аккаунта нет**, но надоело заново выдавать разрешения после каждой сборки: создайте в «Связке ключей» (Ассистент сертификации → Создать сертификат) самоподписанный сертификат типа «Подпись кода» с именем, например, `SmartLayout Local`, и собирайте с `SIGN_ID="SmartLayout Local"`. macOS будет узнавать приложение по сертификату, и разрешения «Универсальный доступ» и «Мониторинг ввода» перестанут слетать. На чужих Mac такая сборка всё равно не пройдёт Gatekeeper.

## Сравнение с RuSwitcher

| | SmartLayout 1.0 | RuSwitcher |
|---|---|---|
| Как исправляется раскладка | автоматически на границе слова, плюс раннее определение по первым 3–5 буквам | по триггеру (тап ⌥) и в бета-режиме автоматически |
| Таблица клавиш | 1.0: статичная, «Русская — ПК». 1.1: по включённым раскладкам через `UCKeyTranslate`, встроенная — запасная | динамическая через `UCKeyTranslate`, любая пара раскладок, включая иврит |
| Орфография и ИИ | словарь опечаток, `NSSpellChecker`, LLM (OpenAI, xAI, YandexGPT, Ollama) с проверкой «не похоже на нейросеть» | нет (только раскладка) |
| Исключения | слова (Backspace после исправления), выученные слова. С 1.1 ещё и приложения: терминалы, IDE и менеджеры паролей исключены по умолчанию | три списка: приложения, «никогда», «всегда». Терминалы, IDE и менеджеры паролей исключены по умолчанию |
| Secure Input | 1.0: не обрабатывается. 1.1: монитор и ИИ пропускают защищённый ввод и поля паролей, в меню горит 🔒 | неактивирующая плашка «на паузе» |
| Свои события | помечаются `eventSourceUserData`, перехватчик их пропускает | так же |
| Перехват отключился | включается заново в обработчике, после сна и раз в 10 секунд | так же |
| Тесты | `swift test` (логика) и pytest (словари, исходники, сборка) | xUnit для Windows-версии, для macOS тестов в репозитории нет |
| Дистрибуция | 1.0: ad-hoc `.dmg`, только arm64. 1.1: universal, hardened runtime, `SIGN_ID` и нотаризация в `build_app.sh dmg` | universal `.dmg` с подписью Developer ID и hardened runtime, Homebrew cask, проверка обновлений |

Из RuSwitcher в 1.1 перенесены динамическая таблица клавиш, исключения по приложениям с защищёнными менеджерами паролей, обработка Secure Input и правило «лучше пропустить, чем исправить неправильно». Ещё можно взять проверку обновлений и Homebrew cask, но для этого нужен публичный канал раздачи.
